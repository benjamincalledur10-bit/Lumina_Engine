# Lumina Engine

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)
[![Mod loader: Fabric](https://img.shields.io/badge/Mod%20loader-Fabric-dbd0b4.svg)](https://fabricmc.net/)

Lumina Engine is an open-source Minecraft mod for Fabric focused on optimizing
and integrating the Lumina shader ecosystem.

> [!IMPORTANT]
> Lumina Engine is currently in early development. There are no stable releases
> available yet, and its features and requirements may change.

## Goals

- Provide a solid foundation for the Lumina shader ecosystem.
- Improve shader performance and resource usage.
- Make Lumina components easier to integrate and maintain.
- Offer a smooth experience alongside the Fabric modding ecosystem.

## Installation

Installation instructions will be added when the first public build is
available. Future releases will be published on this repository's
[Releases](https://github.com/benjamincalledur10-bit/Lumina_Engine/releases)

Never download the mod from an unofficial source.

Please remember that the project is still taking shape. Contribution guidelines
